📄 SEÇÃO 1: ALTERAÇÕES NO HTML (Estrutura do Jogo)
1. Como alterar o título principal que aparece no topo da página do jogo?
🔍 Busca (Ctrl + F): <h1>
✏️ Código Antes vs. Depois:

<h1>Jogo da Velha</h1>


<h1>Super Jogo do [Seu Nome]</h1>
👁️ Resultado Visual: Clique em RUN. O título principal no topo da página mudou de nome!
2. Como mudar os textos de instrução das caixas de cadastro dos jogadores?
🔍 Busca (Ctrl + F): Jogador X
✏️ Código Antes vs. Depois:

<label for="player1">Jogador X</label>
<label for="player2">Jogador O</label>


<label for="player1">Primeiro Jogador (Letra A):</label>
<label for="player2">Segundo Jogador (Letra B):</label>
👁️ Resultado Visual: Clique em RUN. Os textos sobre as caixas de digitar o nome mudaram.
3. Como personalizar o texto e adicionar um emoji no botão de entrada do jogo?
🔍 Busca (Ctrl + F): Iniciar Jogo
✏️ Código Antes vs. Depois:

<button class="btn-start" onclick="startGame()">Iniciar Jogo</button>


<button class="btn-start" onclick="startGame()">COMEÇAR A BATALHA! ⚔️</button>
👁️ Resultado Visual: Clique em RUN. O botão verde inicial ganhou um novo texto com emoji.
4. Como alterar o texto dos botões que aparecem abaixo do placar do jogo?
🔍 Busca (Ctrl + F): Próxima Rodada
✏️ Código Antes vs. Depois:

<button class="btn-reset" onclick="resetBoard()">Próxima Rodada</button>
<button class="btn-start" onclick="resetAll()">Trocar Jogadores</button>


<button class="btn-reset" onclick="resetBoard()">Jogar Novamente 🔄</button>
<button class="btn-start" onclick="resetAll()">Sair do Jogo 🚪</button>
👁️ Resultado Visual: Clique em RUN, entre no jogo e veja os botões de baixo modificados.
🎨 SEÇÃO 2: ALTERAÇÕES NO CSS (Visual e Cores)
5. Como modificar a cor do fundo da tela do jogo usando um novo gradiente?
🔍 Busca (Ctrl + F): linear-gradient
✏️ Código Antes vs. Depois:
/* ORIGINAL */
background: linear-gradient(135deg, #1e3c72, #2a5298);

/* NOVO */
background: linear-gradient(135deg, #8e44ad, #ff007f);
👁️ Resultado Visual: Clique em RUN. O fundo da página mudou para Roxo e Rosa Neon!
6. Como mudar a classe e a cor da primeira letra personalizada (ex: Letra A)?
🔍 Busca (Ctrl + F): .cell.x
✏️ Código Antes vs. Depois:
/* ORIGINAL */
.cell.x { color: #ff4757; }

/* NOVO */
.cell.a { color: #ff007f; }
👁️ Resultado Visual: Clique em RUN. Quando o Jogador 1 jogar, a letra aparecerá em Rosa Pink.
7. Como mudar a classe e a cor da segunda letra personalizada (ex: Letra B)?
🔍 Busca (Ctrl + F): .cell.o
✏️ Código Antes vs. Depois:
/* ORIGINAL */
.cell.o { color: #2ed573; }

/* NOVO */
.cell.b { color: #00e5ff; }
👁️ Resultado Visual: Clique em RUN. Quando o Jogador 2 jogar, a letra aparecerá em Azul Ciano.
8. Como deixar os quadrados do tabuleiro com bordas totalmente arredondadas?
🔍 Busca (Ctrl + F): border-radius: 12px;
✏️ Código Antes vs. Depois:
/* ORIGINAL */
border-radius: 12px;

/* NOVO */
border-radius: 50px;
👁️ Resultado Visual: Clique em RUN. Os 9 quadrados ganharam um formato arredondado estilo cápsula.
⚡ SEÇÃO 3: ALTERAÇÕES NO JAVASCRIPT (Lógica do Jogo)
9. Como alterar a variável inicial para o jogo começar com a nova letra escolhida?
🔍 Busca (Ctrl + F): let currentPlayer
✏️ Código Antes vs. Depois:
// ORIGINAL
let currentPlayer = "X";

// NOVO
let currentPlayer = "A";
👁️ Resultado Visual: Clique em RUN e clique no tabuleiro. Agora aparece a letra A em vez de X.
10. Como atualizar a regra de troca de turnos entre as novas letras (A e B)?
🔍 Busca (Ctrl + F): === "X"
✏️ Código Antes vs. Depois:
// ORIGINAL
currentPlayer = currentPlayer === "X" ? "O" : "X";

// NOVO
currentPlayer = currentPlayer === "A" ? "B" : "A";
👁️ Resultado Visual: Clique em RUN. A primeira jogada coloca a letra A e a segunda coloca a letra B.
11. Como ajustar a verificação de vitória para anunciar o vencedor correto?
🔍 Busca (Ctrl + F): winnerName =
✏️ Código Antes vs. Depois:
// ORIGINAL
const winnerName = currentPlayer === "X" ? player1Name : player2Name;

// NOVO
const winnerName = currentPlayer === "A" ? player1Name : player2Name;
👁️ Resultado Visual: Clique em RUN e vença a partida. A mensagem de vitória exibirá o nome certo.
12. Como garantir que a nova rodada recomece com a letra inicial escolhida?
🔍 Busca (Ctrl + F): function resetBoard
✏️ Código Antes vs. Depois:
// ORIGINAL (dentro de resetBoard)
currentPlayer = "X";

// NOVO
currentPlayer = "A";
👁️ Resultado Visual: Clique em RUN, vença uma partida e clique em Jogar Novamente. A nova partida começará com A.
